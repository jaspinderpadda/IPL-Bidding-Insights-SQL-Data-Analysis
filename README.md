Utilizing SQL queries, this project delves into the data of Pie-in-the-Sky, an IPL bidding app, to extract valuable insights. From predicting match winners to analyzing bidder points and leaderboard standings, our SQL analytics offer strategic perspectives for optimizing bidding strategies and enhancing user engagement in the dynamic world of IPL auctions
